# weblend

## What is weblend?

weblend is a web-based 3D creation platform that brings professional 3D tools to your browser. No installation needed - just open and create!

### Key Features
- 🎨 3D modeling and animation
- 🎭 Blender-like interface
- 🐍 Python scripting support
- 🤝 Real-time collaboration
- 🚀 WebGL2 & WebGPU powered

## Quick Start

```bash
# Clone and run
git clone https://github.com/imkuldeepahlawat/weblend.git
cd weblend
yarn install
yarn dev
```

## Tech Stack
- React 18 + TypeScript
- Three.js for 3D
- Tween.js for animations
- Tailwind CSS for UI
- Jest for testing
